# Сайт-визитка с трансляцией

Макет сайта-визитки для заказчика. Содержит ссылки на соцсети и виджет прямой трансляции.

## Статус
🟢 Готов к демонстрации

## Стек
- HTML5 / CSS3 (без фреймворков)
- Twitch Embed (iframe)

## Запуск
Открыть `index.html` в браузере или запустить локальный сервер:
```bash
python -m http.server 8000 --directory .
```

## Структура
- `index.html` — основная страница
- `styles.css` — стили
- `assets/` — изображения (аватар, лого)

## Плейсхолдеры
Все данные (никнейм, ссылки, описания) являются заглушками и заменяются на реальные данные заказчика.
